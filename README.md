# НЕЙРОЛАБ

Интерактивная лаборатория нервной, гуморальной и нейрогуморальной регуляции для 9 класса. Без регистрации, внешних API и базы данных.

## Быстрый запуск

Требуется Node.js 20 или новее. После клонирования репозитория установите зависимости и соберите приложение:

```powershell
git clone https://github.com/Peternub/NeiroHab.git
cd NeiroHab
npm ci
npm run build
```

Затем дважды нажмите **«Запустить НЕЙРОЛАБ.cmd»**. Откроется браузер по адресу **http://127.0.0.1:4173/**. Окно сервера нужно оставить открытым. Папки `node_modules` и `dist` создаются локально и не хранятся в Git.

В готовом ZIP-архиве сборка уже включена в папку `dist`; устанавливать зависимости для запуска этой сборки не требуется.

Альтернативный запуск из папки проекта:

```powershell
node scripts/serve.mjs
```

На другом компьютере требуется Node.js 20 или новее. Размещать сайт можно на любом статическом хостинге с HTTPS: загрузите содержимое `dist`. Открытие `index.html` двойным нажатием через `file://` не поддерживает модули и PWA.

## Что работает

- Модель: десять интерактивных органов, три режима, подписи, увеличение, перемещение, импульсы и частицы гормонов, рецептор клетки-мишени.
- Эксперименты: испуг, углеводная пища, три интенсивности нагрузки; запуск, пауза, отдельные этапы, повтор и объяснение.
- Управление: независимые воздействия стресса и нагрузки, постепенный ответ, два темпа восстановления, графики и причинные цепочки.
- Урок: пять шагов общей длительностью 180 секунд, полноэкранный режим, ручные переходы, пауза, замедление и итоговая таблица.
- Игра: пять ситуаций, подсказки, 100/50/0 баллов в зависимости от попытки, максимум 500, разбор ошибок и повтор.
- PWA: локальные ресурсы сохраняются после первого открытия собранной версии; приложение доступно без интернета. Установка в отдельное окно — через меню поддерживающего браузера.
- Анимации отключаются кнопкой внизу страницы; настройка сохраняется. Учитывается системное предпочтение уменьшенного движения.

## Показ на уроке

1. Модель и три режима — 1 минута.
2. Испуг с замедлением и пояснениями — 2 минуты.
3. Глюкоза и отрицательная обратная связь — 1,5 минуты.
4. Ползунки нагрузки и восстановление — 1 минута.
5. Несколько игровых заданий — 2–3 минуты.

Пробел запускает и останавливает симуляцию. В уроке стрелки ← → меняют шаг. Кнопки доступны через Tab и Enter. Отдельная кнопка в шапке включает полный экран; при ограничениях встроенного окна откройте обычный браузер и нажмите F11.

## Учебная модель

Показатели иллюстрационные, не предназначены для диагностики. Проценты ползунков задают условную интенсивность воздействия и не измеряют стресс человека. В `src/simulation.ts` заданы отдельные опорные состояния для стресса и нагрузки с интерполяцией между ними. При сочетании воздействий используется более выраженный ответ, без сложения до необоснованных значений. При восстановлении модель постепенно приближается к исходному состоянию. Временная шкала опытов сжата для демонстрации.

SVG показывает условный вид спереди: левая сторона тела расположена справа для наблюдателя. Органы и сосуды не в масштабе, глубина расположения не отображена. Клетка с рецептором показана отдельной схемой. Нервный импульс, синаптическая и гормональная передача различаются в объяснениях.

Материал сопоставлен с учебниками OpenStax; официальная экспертиза по конкретному российскому школьному учебнику не проводилась:

- [Регуляция секреции гормонов](https://openstax.org/books/biology-2e/pages/37-4-regulation-of-hormone-production)
- [Эндокринные железы](https://openstax.org/books/biology-2e/pages/37-5-endocrine-glands)
- [Нервный импульс](https://openstax.org/books/anatomy-and-physiology-2e/pages/12-5-the-action-potential)
- [Двигательные ответы и рефлексы](https://openstax.org/books/anatomy-and-physiology-2e/pages/14-3-motor-responses)
- [Гормоны и рецепторы](https://openstax.org/books/anatomy-and-physiology-2e/pages/17-2-hormones)

## Разработка и проверки

React + TypeScript, Vite, собственные компоненты, SVG-анимации и графики. Шрифты и изображения из внешней сети не загружаются.

```powershell
npm install
npm run dev
npm test
npm run build
```

Сборка проверяет TypeScript и генерирует Service Worker с полным перечнем файлов и версией кэша по отпечатку ресурсов. Для проверки PWA используйте готовую сборку через `node scripts/serve.mjs`, а не режим разработки.

Тесты проверяют исходное состояние, направление ответа, границы модели, восстановление, сценарии глюкозы, начисление очков, продолжительность урока и ссылки на органы.
